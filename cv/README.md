# cv/

- `input/cv-data.json`: the only file you edit to change the Hoja de Vida (from chat or by passing another JSON to the generator).
- `output/`: PDF/DOCX generated by `scripts/hv/generate-cv-pdf.py`. These are the files the web offers for download.

Regenerate with `pnpm generate:cv` (or the `cv-generate` MCP tool). Full flow: `docs/CV_MANAGEMENT/WORKFLOW.md`.
